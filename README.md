## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/yourusername/portfolio.git
```

Navigate to the project:

```bash
cd portfolio
```

Open the project using VS Code and run with Live Server.

## ▶️ Running Locally

Since this portfolio uses React through CDN links, no build process is required.

Simply:

1. Open `index.html`
2. Start Live Server
3. Open the generated localhost URL
